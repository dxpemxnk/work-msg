# Ручная проверка мессенджера — 22.10.2026

Проверка выполнена через интерфейс локального приложения во встроенном браузере.
Основная раскладка проверялась при размере окна 1440×900. Пользователи Алексей
и Анна переключались последовательно в одной вкладке; это не проверка двух
независимых одновременных сеансов.

## Подтверждено

- Отправка сообщения клавишей Enter и кнопкой отправки.
- Отправка ответа; переход по цитате подсвечивает исходное сообщение.
- Добавление реакции 👍 и сохранение её у другого пользователя.
- Закрепление сообщения, отметка рядом со временем и системное оповещение.
- Открытие списка закреплённых в Popover; переход по тексту старого
  закреплённого сообщения загружает нужный участок истории и подсвечивает его.
- Поиск тестового сообщения в группе: найдено одно совпадение,
  переход к результату работает.
- Пересылка сообщения из группы в личный диалог с указанием исходного автора.
- Получатель видит пересланное сообщение и может отправить ответ.
- Счётчик непрочитанных сбрасывается; отправитель видит статус «Прочитано».
- У своего сообщения в группе отображается «Прочитали 1 из 3»;
  список прочитавших содержит Анну и кнопку «Написать».
- В меню чужого сообщения отсутствует пункт «Кто прочитал».
- Карточка участника справа содержит имя, @login, статус и действия;
  кнопка «Написать» открывает личный диалог.
- Три быстрых цикла группа → личный диалог не смешали истории.
- После остановки сервера отображается «Нет соединения».
- После запуска сервера соединение и история восстановились без перезагрузки;
  новое сообщение отправилось и получило статус «Доставлено».

## Ограничения и оставшиеся проверки

- При отсутствии соединения поле ввода отключено. Новые офлайн-сообщения
  через интерфейс сейчас создать нельзя; очередь после потерянного ACK
  этим сценарием не проверялась.
- При исходной ширине около 320 px открытая правая панель занимала видимую
  область чата. Мобильная раскладка не принята по результатам этой проверки.
- Вторую вкладку инструмент открыть не смог: тайм-аут localhost.
  Одновременная работа двух пользователей и статусы присутствия между
  независимыми сеансами не подтверждены этой ручной проверкой.
- Реальные аудио/видеозвонки, групповой звук, камера и микрофон не проверены.
- Не проверены вручную: приглашение/исключение участников, окно из 500+
  сообщений, намеренная временная HTTP-ошибка синхронизации и потеря ACK.
- В консоли зафиксировано предупреждение Vite о подключении HMR WebSocket;
  рабочая отправка сообщений и восстановление Socket.IO при этом подтверждены.
